# Getting started

#### Install dependencies

```bun install```

#### Setup

```bun migration:run```

#### Start local server

```bun dev```

#### Start ngrok tunnel

>! Install and sign up for ngrok cli. [ngrok](https://ngrok.com/)

```ngrok http {port}```

>! Run in different terminal
